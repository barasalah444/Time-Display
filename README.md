# Time Display Application ⏰

A simple Django web application that displays the current date and time dynamically using Django templates and Python's `datetime` module.

##  Features

- Displays current date formatted as `Month Day, Year`.
- Displays current time formatted with AM/PM.
- Clean and minimal UI.

##  Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3
